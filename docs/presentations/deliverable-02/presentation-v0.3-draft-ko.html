📕 BookListing CRUD

🔐 로그인, ✅ 검증, 🧩 서비스, 🗄️ 트랜잭션, 테스트 패턴을 재사용합니다.

📝 BorrowRequest 업데이트

같은 모듈을 재사용하고 유효한 상태 전환 규칙을 추가합니다.

🟨 React 연결

백엔드 규칙을 다시 만들지 않고 검증된 📤 JSON API를 사용합니다.

📝 향후 신고 서비스

인증, 검증, 영속성, 프라이버시 안전 응답을 재사용합니다.

🛡️ 향후 관리자 경계
