## Brain-first operating rule

이 공개 저장소를 직접 가리키거나 개인 실험실 archive를 가리키더라도, Web1 작업은
항상 private brain에서 시작한다.

```text
1. /home/sugonyu/jd/b2/test/test_py/b3-web1/note/TODO.md
   → 오늘의 우선순위와 blocker 확인
2. private brain의 최신 기록
   → 실제로 끝난 일과 남은 일 대조
3. 이 공개 저장소의 board·journal·milestone
   → teacher-facing evidence 확인
```

공개 repo는 결과와 증거의 확인 장소이지, 오늘의 개인 행동을 결정하는 source of
truth가 아니다. `note/`는 개인 로컬 brain이며 commit·push하지 않는다.

## Repository Boundary

This repository contains only teacher-facing project requirements, source code,
submission evidence and public project documentation. Personal study notes and
internal planning are maintained outside this repository.
