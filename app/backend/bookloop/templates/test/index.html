1 · Clients

사용자가 보는 HTML 화면이다. 파일을 제공하고 화면을 만드는 위치가 서로 다르다.

🐍 Jinja client

Flask가 Python 데이터를 Jinja template에 넣어 완성된 HTML을 browser에 보낸다.

Python data → Jinja render → HTML response

🟨 Vanilla UI via 🐍 Flask

화면 코드는 독립 Vanilla JavaScript이지만 Flask가 정적 HTML·CSS·JS 파일을 제공한다.

Flask serves files → JavaScript runs in browser → fetch API

🟨 Independent JavaScript / Vanilla client

WordPress Docker static server가 HTML·CSS·JavaScript를 제공하고, browser의 JavaScript가 port 5000의 Flask API를 호출한다. 서로 origin이 달라 CORS가 필요하다.

Static server :8080 → browser JavaScript → Flask API :5000

2 · API

📤 JSON health API

사용자 화면이 아니라 client가 읽을 구조화된 JSON data를 반환한다.

Flask service → JSON response → client consumes data

3 · Developer Tools

🗄️ Developer Database Inspector

User, BookListing과 BorrowRequest row를 읽기 전용으로 확인하는 로컬 디버깅 도구다. 제품 client나 Admin 기능이 아니다.

DEBUG + ENABLE_DEV_DB_INSPECTOR=true → /dev/db

개발 설정이 꺼져 있거나 debug mode가 아니면 보안을 위해 404를 반환한다.
