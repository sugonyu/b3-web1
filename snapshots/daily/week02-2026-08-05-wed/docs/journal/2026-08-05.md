## Decisions and learning

- A snapshot must preserve more than source code. The Code Map, presentation,
  Kanban and verification evidence must describe the same frozen state.
- Snapshot-internal links should use relative paths whenever possible. Live
  `localhost` links are useful for the current development copy but are not a
  reliable reference for a frozen artifact or future HTML book.
- `db.init_app(app)` connects the SQLAlchemy extension to an existing Flask app;
  it is not the creation of a second Flask application context.
- The application factory is shared as a construction rule. HTTP and CLI execution
  create their own short-lived contexts instead of sharing one global context.
