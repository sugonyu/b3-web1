# Web Project 1

Student project repository for Web Project 1 (`582-32W-VA`), Summer 2026.

## Project

The current project direction is **BookLoop**, a privacy-conscious community
directory for sharing Korean-language books in Montreal.

## Current Status

- Deliverable 1 definition and design: complete
- Deliverable 2: backend foundation and first vertical slice in progress
- Public source: Flask, SQLAlchemy, SQLite, Jinja, Vanilla API client, and tests
- Working stack: React + Flask JSON API + Flask-SQLAlchemy + SQLite

Client progression:

```text
Vanilla JavaScript API check
→ Python/Jinja Deliverable 2 verification
→ React Deliverable 3 product client
```
