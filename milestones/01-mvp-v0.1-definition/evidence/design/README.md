# Design Evidence

This folder contains the planned design-system evidence for the BookLoop
Deliverable 1 proposal. Figma is not assumed to be mandatory; an equivalent
design-system page may document the same decisions.

Required evidence:

- desktop and mobile layouts
- visual hierarchy
- reusable components
- typography and colour system
- form states
- loading, empty, success and error states where relevant
- short design rationale

Current direction:

- Use a minimal, privacy-conscious visual language.
- Document desktop and mobile layouts, reusable components, and state changes.
- Keep the public evidence aligned with the final BookLoop workflow.

Public presentation evidence:

- [Design System section](../../presentation.html#design)
- colour tokens and 60/30/10 rationale
- reusable button and status components
- responsive desktop-to-mobile rule
- loading, empty, success, error, hover and disabled state plan
