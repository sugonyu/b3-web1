핵심 답

Define → HMW → Ideate는 B3 UI/UX 수업 자료에서 직접 확인된다. 가장 강한 근거는 b3-uiux/class04/index.html이다. 

Define User Needs
→ "I want to [action] so that [benefit]"

Ideate
→ "How might we [action] for [user]?"
→ 문제를 가능한 해결책의 질문으로 재구성하고 brainstorm

이 과목에서는 HMW를 별도 단계가 아니라 Phase 3: Ideate 안에서 사용하는 핵심 질문 도구로 분류한다. 따라서 수업 약칭은 Define = User Story, Ideate = HMW + 아이디어 도출이 가장 정확하다.

반면 PRD → FRD → Acceptance Criteria → Development는 수업 자료의 직접 문장이 아니라 UI/UX 학습을 현업 개발 문서로 연결한 병렬공부 해석이다.

BookLoop 적용

Define
몬트리올의 한국책 접근성과 개인정보 노출 문제

HMW
어떻게 하면 개인정보를 공개하지 않고 책을 빌릴 수 있게 할까?

Ideate
요청 → 소유자 승인·거절 → 승인 전 개인정보 비공개 → 반납 기록

PRD
target user, scope와 primary workflow

FRD
pending BorrowRequest와 status transition

Acceptance Criteria
Given / When / Then으로 검증 가능한 완료 조건

UI/UX 훈련은 visual styling을 넘어 user flow, state, component, API, validation과 browser verification을 사용자 관점에서 설계하는 개발 능력으로 전이된다.
