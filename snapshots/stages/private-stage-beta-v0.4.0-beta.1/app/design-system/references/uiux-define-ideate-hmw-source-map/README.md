## Boundary

수업 자료에서 직접 확인되는 내용과 현업 병렬 해석을 구분한다.

```text
UI/UX 수업에서 직접 확인
→ Define, User Story, HMW, Ideate와 Design Thinking 흐름

Tony/Codex 병렬 해석
→ PRD, FRD, Acceptance Criteria, Architecture, API와 Code 연결
```

`PRD → FRD → Development`는 UI/UX 수업 자료의 직접 문장이 아니라, 수업에서
배운 문제 정의와 아이디어 과정을 현업 제품 개발 문서에 연결한 분석이다.
