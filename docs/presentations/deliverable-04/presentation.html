01 · Deliverable 3 feedback

Three comments defined the D4 improvement path

📖 Book details page

Move from a dense list row to a dedicated page with the information needed before requesting.

💬 Optional request comment

Let the borrower explain the request without turning BookLoop into a chat system.

🌐 Korean language button

Make the main product interface easier to use in Korean while keeping English and French available.

D4 does not hide the feedback in a backlog. Each comment maps to one small, testable product change.

Books list→Book details→Request action

Useful context

04 · Feedback → Language support

Korean became part of the interface

🇰🇷 Korean

Navigation, form labels, placeholders and product messages can be displayed in Korean.

🇬🇧 English

The original interface remains available as the stable baseline.

🇫🇷 French

The same fixed UI layer supports the local Montreal context.

Only fixed interface text is translated. User-entered book titles, authors and request messages preserve their original language.

Recorded verification: JavaScript syntax check and 11 book-management Flask tests.

05 · Unofficial review → Mina awareness policy

Mina learns about a report only after Admin starts the review

Fig 5-1 · Exact activation point

Tony submits Report
Status: Open→Admin checks context
Mina sees nothing→Admin selects Under review→Mina opens related Request detail
Notice appears

Fig 5-2 · What Mina sees by Report status

Report stateWhat Mina seesWhat remains hidden
No Report“No active Admin review notice”No Report data exists.
OpenThe same “No active” message; she cannot distinguish Open from no Report.Report existence, reporter, category and details.
Under review“Admin review notice” and the number of active reviews for this exchange.Reporter name, category, details and Admin notes.
Resolved / DismissedThe active notice disappears in the current implementation.No closure history or outcome is shown to Mina.

Fig 5-3 · Decision and privacy rules

Review questionD4 responseBoundary
How should Mina decide?The owner request detail includes a clear decision guide.The guide supports judgment; it does not decide automatically.
Where does Mina see the notice?Only on the related Request detail when she is the reported listing owner.No email, push notification or global inbox exists.
Can Mina identify Tony?The notice does not display the reporter, but a two-party Request may allow inference.BookLoop does not promise anonymity.
Does the Report decide the request?No. Mina still chooses Approve or Reject.Admin review and borrowing decisions remain separate.

Current limitation: this awareness query is owner-side. If the borrower is the reported user, the same notice path is not yet implemented. Resolved/Dismissed closure notice is also absent.

Recorded checks: 39 focused Decision/Admin tests and 162 full backend regression tests.
